# Kalki, anglicyzmy, kolokacje widmo, fałszywi przyjaciele

Spis: 1. Skan kalek jako TEST  2. Kalki składniowe  3. Anglicyzmy leksykalne i biznesowe
4. Kolokacje widmo  5. Fałszywi przyjaciele  6. Cyrylica (homoglify)  7. Co zostawić

## 1. Skan kalek jako TEST (nie zamknięta lista)
Listy nie da się domknąć. Dla podejrzanego zwrotu: (a) przetłumacz wstecz na angielski
— jeśli to kalka, od razu widać; (b) czy jest prostsze polskie słowo; (c) czy pasuje do
rejestru. Po KAŻDej podmianie anglicyzmu przeczytaj całe zdanie i spytaj: „czy ktoś by
tak naturalnie powiedział?".

## 2. Kalki składniowe (przed → po)
- „tak długo, jak (się robi)" → „dopóki (się robi)" [STYL, nie BŁĄD]. Wg PWN konstrukcja
  jest poprawna, a drugie „długo" zbędne (K. Kłosińska, zrodla.md). „Dopóki" to tylko
  oszczędniejsza alternatywa; proponuj, nie poprawiaj jako błąd.
- „wydaje się być" → „wydaje się" / „jest".
- „w oparciu o" → „na podstawie" / „według".
- „adresować problem" / „zaadresować potrzebę" → „zająć się" / „odpowiedzieć na potrzebę".
- „dostarczać wartość" → „wnosić wartość" / „dawać coś od siebie".
- „być w stanie" → „móc".
- „ma to sens" → „to logiczne" / „to ma ręce i nogi".
- „na koniec dnia" / „w ostatecznym rozrachunku" → „ostatecznie" / „w końcu" (często tnij).
- „wywierać wpływ" → „wpływać".
- „w kontekście X" → „jeśli chodzi o X" / „co do X".
- „na poziomie X" → „w zakresie X" (albo przebuduj).
- „dedykowany" → „przeznaczony" / „skierowany do" / „osobny".
- „pójść głębiej w temat" / „deep dive" → „zgłębić" / „wgryźć się".
- „w temacie X" → „w sprawie X".
- „celem (zrobienia)" → „żeby/aby".
- „posiadać" (nadużywane) → „mieć".
- „w przypadku, gdy" → „gdy" / „jeśli".
- „pomimo faktu, że" / „z uwagi na fakt, że" → „mimo że / choć", „bo / ponieważ".
- „na chwilę obecną" / „na dzień dzisiejszy" → „teraz" / „obecnie".
- „procesować" → „przetwarzać"; „requestować" → „żądać/prosić"; „alignować się" → „uzgadniać".
- „bazować o" → „bazować na"; „dyskutować temat" → „dyskutować o/nad tematem".
- Zawieszony przysłówek (szyk angielski): przysłówek po dopełnieniu, gdy naprawdę
  określa rzeczownik → zamień na przymiotnik i przesuń przed rzeczownik. „przepływu
  informacji cyklicznie" → „cyklicznego przepływu informacji". [STYL, heurystyka]

### 2b. Uźródłowione pary z poradników (sprawdzone w skanie lub w PDF cyfrowym)
- Konstrukcja rozszczepiona (what-cleft), częsta w tekstach AI: „To, czego chcą, to
  zemsta” → „Chcą zemsty”. („What they want is revenge zostało przetłumaczone dosłownie”,
  Pisarska, Tomaszkiewicz, Współczesne tendencje przekładoznawcze, Poznań 1998, s. 160.)
  Wzorzec ogólny: „To, co X robi, to Y” → „X robi Y”. [STYL]
- „filozofia zarządzania” → „sposób zarządzania”; „optyka widzenia” → „punkt widzenia”
  (A. Wolański, Polszczyzna na co dzień, s. 9: pretensjonalność). [STYL]
- „ekonomia tego kraju” (o gospodarce) → „gospodarka kraju” (Pisarska, Tomaszkiewicz,
  s. 160; przykład z francuskiego, ten sam mechanizm przy ang. economy). [BŁĄD znaczeniowy]
- Ze słowniczka „Jak pisać o Funduszach Europejskich?” (MRR 2010, s. 129–134), z oceną
  autorów w nawiasie:
  - „wsparcie dla kogoś/czegoś” → „wsparcie kogoś/czegoś” (niepoprawne);
  - „warunek dla czegoś” → „warunek czegoś” (niepoprawne);
  - „niezbędny dla czegoś” → „niezbędny do czegoś” (niepoprawne);
  - „skierowany dla kogoś” → „skierowany do kogoś/czegoś” (niepoprawne);
  - „pełnić rolę” → „pełnić funkcję” / „odgrywać rolę” (niepoprawne, kontaminacja);
  - „fakt zrobienia czegoś” („fakt zgłoszenia wniosku”) → „zgłoszenie wniosku” (niepoprawne);
  - „kondycja” o obiektach nieżywotnych („kondycja gospodarki”) → „sytuacja” / „stan”
    (niepoprawne);
  - „mieć miejsce” → „coś się zdarzyło / wydarzyło” (nadużywane);
  - „w obszarze czegoś” / „na obszarze czegoś” → nazwij rzecz wprost (nadużywane).
  UWAGA: to ocena autorów poradnika, nie PWN/RJP. Przed werdyktem [BŁĄD] sprawdź w
  zrodla.md; bez potwierdzenia dawaj [STYL].
- Kolejka do weryfikacji (z „Form i norm” Kłosińskiej, tylko OCR, NIE cytować jako źródła
  przed sprawdzeniem w skanie): biznes informacje, krem dla cery, numer jeden na świecie,
  projekt = film/płyta, inteligentny/agresywny o rzeczach, wiodący, w pierwszym rzędzie.

## 3. Anglicyzmy leksykalne i biznesowe (→ polskie)
deep dive → zgłębienie/analiza; pain point → bolączka/problem; call → rozmowa/spotkanie;
insight(s) → wniosek/spostrzeżenie; feedback → informacja zwrotna / uwagi; deadline →
termin; ASAP → jak najszybciej; update → aktualizacja/nowość; mindset → nastawienie;
flow → przepływ/rytm; case → przypadek; benefit → korzyść; framework → ramy/szkielet;
approach → podejście; leverage → wykorzystać; skillset → zestaw umiejętności;
challenge → wyzwanie/problem; milestone → kamień milowy (tylko jak realny etap).
Korpo-sztandar do cięcia: synergia, ekosystem, holistyczna perspektywa, kompleksowe
podejście, deliverables.
Korpo-czasowniki (spolszczone kalki) → polski: alignować się → uzgadniać; eskalować →
przekazać wyżej; deliverować → dostarczać/wdrażać; ownować → odpowiadać za; performować
→ działać/wykonywać; pushować → wprowadzać; requestować → prosić/wnioskować; revertować
→ wycofać; trackować → śledzić; matchować → dopasowywać; facilitować → prowadzić;
kommitować się → zobowiązać się; pivotować → zmienić kierunek; skopować → określić zakres.
(To [STYL]/rejestr, nie błąd normy; w żargonie zespołu dev bywa OK — tłumacz w komunikacji do klienta.)

## 4. Kolokacje widmo (KRYTYCZNE, najczęściej przeoczane)
Oba słowa poprawne, ale para nie istnieje w polszczyźnie:
- „rusztowanie pojęciowe" → „szkielet pojęciowy".
- „zbiegać na wniosku" → „prowadzić do wniosku".
- „budować rapport" → „budować więź / relację".
Po każdej zmianie anglicyzmu sprawdź, czy nowa kolokacja realnie funkcjonuje.

## 5. Fałszywi przyjaciele (wymagają kontekstu, sama obecność to nie błąd)
aktualnie (≠ ang. „actually" = właściwie; „aktualnie" = obecnie); ewentualnie
(≠ „eventually" = ostatecznie); sympatyczny (≠ „sympathetic" = współczujący);
transparentny (często lepiej „przejrzysty"); definitywnie (≠ „definitely" = na pewno);
dekada (po polsku też „10 dni"); kondycja (≠ „condition" = warunek; częstszy kłopot to
„kondycja” o rzeczach zamiast „stan”, patrz 2b).

## 6. Cyrylica (homoglify) — twardy błąd
W polskim tekście nie może być znaków `[А-Яа-яЁё]`. Litery а/о/с/е/р/х wklejone z rosyjskich
źródeł wyglądają jak łacińskie, ale psują wyszukiwanie i pisownię. Końcowy grep musi dać 0.

## 7. Co ZOSTAWIĆ (nie poluj na to)
Żargon autora i realne terminy dziedzinowe: commit, deploy, branch, merge, endpoint,
cache, API, MVP, tag. To nazwy rzeczy, nie kalki do tępienia. Standardy branżowe
(SSO, VLAN) zostają. Jeśli polska forma z sufiksem istnieje w SJP/WSJP — można; jeśli nie
(„fetchować", „scrollować") — podmień („pobierać", „przewijać"), chyba że to świadomy żargon.
